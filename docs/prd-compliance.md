## Dashboard/history implementation status (2026-10-20)

The authenticated `GET /api/v1/dashboard/playback-history` returns only the caller's existing `Interaction` records and labels provenance as `self_reported`. It does not imply externally verified playback. The connected player can submit an app-observed completion only when a real catalog audio asset reaches its `ended` event and the duration matches catalog metadata; current seed tracks have no audio assets, so this path is presently unavailable. `GET /api/v1/dashboard/lounges/:id/analytics` is membership-checked; duration returns `null` because session start time is not persisted, while counts come from QueueEvent documents, Soundclash battles from `soundclash.opened` records, and sentiment points/message totals from persisted ChatMessage documents. Peak concurrent participants and AI DJ question count also return `null` because those facts are not durably persisted. The session snapshot, rejoin/taste dashboard and complete analytics reconciliation are not implemented. Unit tests use an injected fake repository; no new Mongo integration test was run. Full details and exact contracts are in `server/API.md#dashboard-history-and-lounge-analytics`.

## Frontend/API integration increment (2026-10-20)

Account/Profile uses register/login, refresh-cookie session restoration, `/auth/me`, and logout; access JWTs remain in memory and roles are taken only from backend responses. Search uses the public `GET /api/v1/tracks` catalog. Queue joins using `lounge.join`, subscribes to room-filtered `lounge.queue.update`, sends `lounge.queue.add` and `.vote`, and can request an authoritative `lounge.sync.request` snapshot. Reconnect reissues the join for a fresh state; listeners are removed on disconnect/unmount. Backend track IDs are retained across search, queue and player selection.

The persistent player uses browser audio if a catalog track has `audioAssetUrl`. It submits one completed Interaction only from the audio element's `ended` event for a real catalog track whose measured duration is within one second of metadata. This is app-observed, client-reported playback, not external listening verification. Current seed tracks have no playable audio URLs, so play controls remain unavailable and mock selections never create history. No streaming provider or licensed catalog is integrated.
